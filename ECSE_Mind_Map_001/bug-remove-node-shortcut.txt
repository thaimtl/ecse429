Pre Conditions
- A map with at least one non-root node
- macOS 26.5.1 / arm64 / FreeMind 1.0.1 / JDK 21

Steps to Reproduce
- Select a non-root node
- Press Delete (backspace). Nothing happens
- Press Fn+Delete (forward delete). Nothing happens
- Right click the node. The context menu lists "Remove Node" with a
  keyboard shortcut displayed beside it
- Click "Remove Node". The node is removed

Bug Description
- The context menu advertises a keyboard shortcut for "Remove Node", but
  no key press invokes it. The node can only be removed through the menu.
- The shipped configuration shows why. In freemind.properties the action
  behind this menu item is bound to nothing:
      keystroke_remove = none
  while the delete key is claimed twice by two other actions:
      keystroke_delete_child     = DELETE
      keystroke_remove_all_icons = DELETE
- A menu item should not display a shortcut that is not configured.

Frequency
- Occurs every time

Productivity Impact
- Removing nodes requires the mouse. For a tester taking notes at speed
  this breaks keyboard flow on one of the most frequent operations.

Notes
