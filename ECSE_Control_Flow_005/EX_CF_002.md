# EX_CF_002 - Staircase

## Number of basis paths

N = 11, E = 13

V(G) = E - N + 2 = 13 - 11 + 2 = **4**

## Basis paths

1. START → Result = 0 → Read → A? → B? → C? → Print → STOP
2. START → Result = 0 → Read → A? → Do A → B? → C? → Print → STOP
3. START → Result = 0 → Read → A? → B? → Do B → C? → Print → STOP
4. START → Result = 0 → Read → A? → B? → C? → Do C → Print → STOP
